# MentiCircle
MentiCircle is a dedicated mentorship platform designed to connect students, alumni, and young professionals through structured and meaningful guidance. The platform provides several key features:
Interest-Based Mentor Discovery,
One-on-One Chat,
Live Mentorship Sessions,
Public Query Forum,
Organized Request System,
Engagement Dashboard,
Recognition System
